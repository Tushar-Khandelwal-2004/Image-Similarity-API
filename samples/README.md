# Sample pairs

Place demo image pairs in this folder before running the benchmark or using preset buttons:

- `identical-source.*` and `identical-suspect.*`
- `filtered-source.*` and `filtered-suspect.*`
- `tampered-source.*` and `tampered-suspect.*`
- additional resized, cropped, text-overlay, and unrelated pairs for manual checks

Accepted image formats are JPEG, PNG, and WebP. Sample files are intentionally not committed to the repository.
